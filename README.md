# CSE 3250
For this final we used circuit breaker to to switch between being in closed or open states if there were too many failures being sent to our site. The restrictions I set in place were so that after 50 entries and 10% of them being a failure it would enter the open state after 2 seconds in that state it then goes into the half open state to allow 10 calls in if  they are under threshold of 10% then the state goes back to closed if not it goes back to open for 2 more seconds and will keep flip flopping in that way. within externalapiservice it is set to fail 10% of the time which has been perfect for my test case as sometimes within 50 calls it will fail less than 10% of tries leading it to go back into the closed state.

a script to test it:
for i in {1..200}; do   echo "Request $i";   curl -s http://localhost:8080/test > /dev/null;    CLOSED=$(curl -s "http://localhost:8080/actuator/metrics/resilience4j.circuitbreaker.state?tag=name:myServiceCB&tag=state:closed" | jq '.measurements[0].value');   OPEN=$(curl -s "http://localhost:8080/actuator/metrics/resilience4j.circuitbreaker.state?tag=name:myServiceCB&tag=state:open" | jq '.measurements[0].value');   HALF=$(curl -s "http://localhost:8080/actuator/metrics/resilience4j.circuitbreaker.state?tag=name:myServiceCB&tag=state:half_open" | jq '.measurements[0].value');    echo "State: CLOSED=$CLOSED OPEN=$OPEN HALF_OPEN=$HALF";   echo;   sleep 0.0001; done
